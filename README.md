# POLE AROMA 処方記録・安全確認ツール(企画中)

小さなアロマ雑貨の作り手のための、**処方の記録と、IFRA にもとづく安全面の確認を補助するツール**。
まずは作り手本人(ハンドメイドのアロマブランド「POLE AROMA」)の業務で使い、効果を測ってから広げる。

## 何を解決するか

> 香りを作るたびに、処方が手書きノートにしか残らず、危険性の高い原料や IFRA の上限を確かめないまま製品にしている。

- 手書きノートの写真を撮ると、**AI(Claude API)が処方を読み取って下書きを作る**。人が確認して保存する。
- 保存した処方を、**IFRA の基準(製品カテゴリ別の上限)と照らし合わせ**、「赤(危険性が高い)/黄(上限超え)/上限に近い/未確認」を示す。
- 計算は決まった式で行い、AI には任せない。**最終判断は作り手がする**(法的な判断はしない)。

## 状況

- 企画フェーズ完了(2026-11-06)。コードを書く前の検証(2時間)で、読み取りの精度と確認の価値を確かめた。
- 次は MVP の実装(約60時間)。
