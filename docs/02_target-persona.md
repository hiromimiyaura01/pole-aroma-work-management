# 02 ターゲットとペルソナ

ステータス:**確定 v1.0(2026-11-05)**
前提:`01_problem-hypotheses.md` v1.0。検証の対象はひろみ自身(**n=1**)。

---

## 1. この文書の考え方

- MVP の利用者は **ひろみ(POLE AROMA)1人** と決めている。メインのペルソナは架空の人物ではなく、**実在のひろみ** にする。
- 「toB(事業者向け)サービス」と言うためには、ひろみ以外の事業者にも当てはまるかが問われる。そこで、**ひろみと同じ条件を持つ事業者** を「想定ターゲット」として分けて書く。
  - 想定ターゲットは **根拠がまだない【仮説】**。数字や実態は、06(市場規模)と任意のヒアリング(仲間1〜2名)で確かめる。
- ペルソナを広げすぎると、60時間の MVP に収まらなくなる。**「誰を対象にしないか」も書く**。

---

## 2. メインのペルソナ:ひろみ(POLE AROMA)【事実】

すべて、2026-11-05 までのひろみの回答と、スプレッドシート・ノートの確認にもとづく。

### 事業の概要
- 個人で運営するハンドメイドのアロマ・フレグランスブランド。
- 製品:ピローミスト、ルームミスト、インヘラー、個人向けのブレンド相談など。
- 販売中の商品は約11種類(スプレッドシート「販売中の商品管理」より)。「ホテル…」とあるのは、ホテルライクな **シリーズ名**。ホテルへの卸しはしていない(ひろみの回答)。
- 販売先は一般のお客さん(toC)。【推測】POLE AROMA 自体には、取引先から安全面の説明を求められる事情はない。

### 香りづくりの流れ
1. 精油をそれぞれアルコールで重さ10%に希釈し、試作する。
2. 手書きのノートに、シリーズ名と番号(例:Tea 012 → 013)をつけて比率(重さ)を書く。トップ・ミドル・ベースのグループと小計も書く。
3. 完成版を、あとでスプレッドシートに書き起こす(ただし、今のシートは昔の滴数ベースのやり方のまま)。
4. 製品には原液を、賦香率8〜15%(固定ではない)で入れる。どの製品向けかは、処方を作る時点で決まっている。

### 原料の持ち方
- 精油は約50〜100本。
- 購入先は複数:マンデイムーン、ARTQ、インセント、ナチュラルサイコス、ナゴミアロマ、NOW FOODS など。今後も増える可能性がある。
- 同じ精油でも、買う容量(10ml/20ml など)と価格が毎回違う。
- COA・SDS は手元にない。

### 今困っていること
| 場面 | 今の状態 |
|---|---|
| 新しい香りを作ったとき | IFRA の上限や危険原料を **確かめないまま** 製品にしている。オークモスのような危険性の高い原料は、確実に除外したい |
| 処方を残すとき | 手書きノートからシートへの **書き起こしが二度手間** |
| 精油を買い足すとき | 2か月に1回ほど、全部の精油を確認して買うものを選ぶ。**1回約2時間**。同じ確認を何度もしている |
| 値付け・利益を考えるとき | いつ・どこで・いくらで買ったかが分からず、原価は **「まぁ赤字にはならんっしょ」** くらい |

### 考え方・こだわり
- IFRA は「必ず対応しないといけないもの」ではないと捉えている。意図して上限を超えたい処方もある(例:ラベンダーたっぷり)。
- 一方で、危険性の高いものは確実に避けたい。
- 「一度調べればずっと使える」情報には、手間をかけてもよい(例:精油ごとの比重)。

### 管理したい理由【事実】(2026-11-05)
- アロマ作家の界隈の **ゆるさが目につく**(例:香水として売ってはいけないのに、それを思わせる売り方をする/「アロマは身体にやさしい!」と言う)。
- **科学的にも安心・安全なアプローチを追求したい**。

### ITスキル・道具
- Google スプレッドシートを使っている(VLOOKUP のような参照式を含むシートを作れる)。
- iPhone で写真を撮る(標準は HEIC 形式)。
- PdM として、データ分析(BigQuery など)の経験がある。【推測】一般的な小規模事業者より、データの扱いに慣れている。→ **ひろみが使えることは、ほかの事業者も使えることの証明にはならない**。

### ひろみの「片付けたい用事」(Jobs to be done)【推測】
1. **新しい香りができたら**、ノートの写真を撮るだけで処方を残し、危険な原料が入っていないか、上限を超えていないかをその場で知りたい。超えるなら、意図して超えたことを残したい。
2. **精油を買い足すときに**、何が残り少ないか、開封から時間がたったものはどれかを、棚を全部見なくても知りたい。
3. **値段を決めるときに**、その商品の原価を根拠のある数字で知りたい。

## 3. 想定ターゲット(toB として広げる先)【仮説】

### 条件(この条件がそろう事業者が対象)
| 条件 | 理由 |
|---|---|
| **安全性や科学的な根拠を重視している**(2026-11-05 追加) | ひろみが管理したい理由そのもの。この考えがない作り手は、管理する動機が弱い【推測】 |
| 1〜数人の小規模な事業者 | 専門の調香師・品質管理の担当者がいない。確認を自分でやるしかない |
| **自分で処方を作り、自分で製造している** | 処方の記録と安全面の確認が、自分の仕事になる |
| 精油を **複数の店から少量ずつ** 買っている | 瓶ごとに価格・容量がばらばらになり、原価と在庫が分かりにくくなる |
| 肌や顔に触れうる「雑貨」を作っている(ピローミスト、ルームミストなど) | IFRA のカテゴリと上限が関わる |
| 手書きやスプレッドシートで管理している | 専用のシステムを入れていない |

### 例として想定する事業者【推測】
- ネットショップやイベントで販売している、ハンドメイドのアロマ雑貨の作家
- オリジナルブレンドを販売・提供している、小さなアロマ教室やサロン

### 対象にしない事業者
| 事業者 | 理由 |
|---|---|
| 中〜大規模のメーカー・OEM | 香料会社から IFRA の適合証明書や SDS を受け取れる。専用の仕組みがある【推測】 |
| 化粧品(薬機法上の化粧品)を作る事業者 | 化粧品の規制は別の確認が必要。このプロダクトでは扱わない |
| 販売せず、趣味で作るだけの人 | 原価や在庫を管理する必要が小さい(toB ではない) |
| 合成香料・フレグランスオイルが中心の事業者 | MVP は精油(天然の単一素材)を前提にしている。香料メーカーの組成情報がないと確認できない |

### ひろみの周りでの当てはまり【事実】(2026-11-05)
- ハンドメイド仲間は、この条件には **当てはまらない**。ひろみの認識では「**アロマを作っている人は少ない**」。
- 合成香料も合わせて使う知り合いが1人いる。MVP の対象外だが、**MVP の先で使ってもらう候補**。
- 【推測】ここから言えること:
  - 想定ターゲットは **かなり小さな(ニッチな)市場** の可能性がある。06 では「大きな市場」ではなく「小さくても、確かに困っている層」として見積もる。
  - 仲間へのヒアリングで反証チェックをするのは難しい。代わりに、**公開情報(ハンドメイドマーケットに出品しているピローミスト・アロマスプレーの作家の数など)** で、条件に当てはまる事業者がどれくらいいるかを確かめる(06 で行う)。
  - toB のポートフォリオとしては、「対象は小さく、まず自分の事業で効果を測った」と正直に書く方が、説得力がある。

### 想定ターゲットについて、まだ分からないこと
- こうした事業者が、どれくらいいるのか(→ 06 市場規模)
- ひろみと同じように「確かめないまま作っている」のか、それとも何かで確かめているのか(→ 03 競合と代替手段、任意のヒアリング)
- お金を払ってでも使いたいと思うか

## 4. n=1 であることの扱い

- ポートフォリオでは、「**まず自分の業務で課題を確かめ、MVP で改善を測り、次に同じ条件の事業者へ広げる**」という進め方として説明する。
- 想定ターゲットの部分は、根拠が増えるまで【仮説】のまま扱う。
- 仲間へのヒアリングは、条件に当てはまる人がいないため **行わない**(2026-11-05)。代わりに公開情報で確かめる(06)。
- MVP の先では、合成香料も使う知り合い1名に試してもらう案がある。
