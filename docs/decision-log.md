- **補足**:Supabase は最初、大きな地域(Asia-Pacific)を選んだらシンガポールになったので、中身が空のうちに東京で作り直した。
- **出典**(確認日 2026-11-06):

## 2026-11-06 処方に「不変の ID」を振り、販売名とは分けて管理する

- **決めたこと**:処方ごとに、変わらない ID を振る。販売名(例:INNOCENT)は別の項目として記録する。同じ販売名のまま処方を変えたときは、新しい ID の処方になる。
- **理由**:ひろみの要望。同じ名前のまま処方を変えていくので、名前だけでは「どの時点の処方か」が分からない。
- **補足**:【推測】これは「完成版だけを記録する」(2026-11-05)と両立する。試作の途中は記録しないが、**完成版が変わるたびに新しい ID** になる。②で製造の記録をつけるとき、「どの ID の処方で作ったか」を残せる(どの瓶・どのロットにどの処方を使ったかを追える)。

## 2026-11-06 写真からの読み取りを MVP の中心機能として採用(V1 の結果)

- **決めたこと**:手書きノートの写真から処方の下書きを作る機能を、MVP の中心にする。あわせて次のルールを決める。
