## 2.5 生活の木 オンラインショップ(2026-11-05 追記。ひろみの紹介)

- URL(例):https://onlineshop.treeoflife.co.jp/collections/aroma/products/084733290(ラベンダー・フランス産)
- 比較のため確認:https://onlineshop.treeoflife.co.jp/products/084733280(ユーカリ・グロブルス)
- 中身:【事実】精油の商品ページに、次の情報が決まった形で載っている。

| 情報 | 掲載 | メモ(ラベンダー・フランス産の例) |
|---|---|---|
| 学名・抽出部位・抽出方法・原産国 | ある | Lavandula officinalis/花・葉/水蒸気蒸留法/フランス |
| **比重(20℃)** | **ある** | 0.885(ユーカリ・グロブルスは 0.9098) |
| 屈折率・旋光度・引火点 | ある | — |
| **主な成分例(%)** | **ある** | 例:酢酸リナリル 36.90%、リナロール 31.90%、カンファー 0.40% など |
| 品質保持の目安 | ある | 未開封:製造後60か月/開封後:12か月以内 |
| ロット番号・COA・SDS | ない | — |

【推測】評価:
- **比重と成分の参考値を、同じ形で取れる有力な情報源**。「一度調べればずっと使える」というひろみの考えに合う。
- ただし、これは **生活の木の商品の代表値**(見出しは「主な成分例」)。ひろみが別のメーカーで買った瓶の実測値ではない。参考値として扱い、出典を残す。
- 確認したのは2ページだけ。ほかの精油にも同じ形で載っているかは未確認。
- 「開封後12か月」の目安は、瓶ごとに開封日を記録する理由にもなる(②の段階)。
