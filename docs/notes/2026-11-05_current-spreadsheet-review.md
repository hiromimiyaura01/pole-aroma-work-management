# 現状調査メモ:精油の価格管理スプレッドシート

- 確認日:2026-11-05
- 対象:ひろみの Google スプレッドシート「販売中の商品」(Google ドライブ経由で読み取り)
- 目的:今の業務がどう回っているか(=現在の代替手段)を、事実ベースで把握する
- 注意:読み取り時に一部のセルが省略表示されていたため、見出しの全文などは未確認。**処方の配合はここに転記しない**(企業秘密にあたるため)。

## 1. シートの構成【事実】

| シート | 中身 | 規模 |
|---|---|---|
| 販売中の商品管理 | 商品ごとのキャッチコピー/メインの精油/コンセプト/レシピの状態(「販売中」「ホテル…」「商品開発…」など) | 約11商品 |
| 精油価格表 | ブランド/精油名/価格/容量(ml)/単価(円/ml) | 約245行。同じ精油が容量ごとに別の行になっている(例:5・10・50・100ml) |
| 処方ごとのシート(9枚) | 精油名/使用滴数/ml単価/使用ml/製造量/合計金額 など | 1枚が1処方。同じ形のシートをコピーして作っている |

## 2. 処方シートの計算の仕組み【事実】

- 1単位あたり **20滴 = 1ml**(1滴 = 0.05ml)で計算している。
- 「使用滴数 × 0.05ml × ml単価」で精油の原価を出し、製造量を掛けて合計を出している。
- 空の行には `#N/A` が並んでいる。【推測】精油名をもとに価格表から単価を引く式(VLOOKUP など)が入っていて、精油名が空なのでエラーになっている。

## 3. 気づいた点

### 3-1. 同じ精油なのに、処方によって ml 単価が違う【事実】
- 例:ヒノキ(253円/ml と 161.7円/ml)、フランキンセンス(68.5円/ml と 85.5円/ml)、オレンジ(25.7円/ml と 32円/ml)、タンジェリン(42.8円/ml と 53.5円/ml)など。
- 【推測】次のどれか(または複数)が原因と考えられる。
  - 処方ごとに、違う容量(5ml 瓶か 100ml 瓶か)やブランドの単価を参照している。
  - ブランドが違う別の精油として登録されている。
  - 価格表を更新したときに、古い数字のまま残っているシートがある。
- → **「その商品の本当の原価」がいくらなのかが、シートからは一意に決まらない状態**になっている可能性がある。
- 【事実】ひろみの回答(2026-11-05):原因は、買う容量(10ml/20ml など)が都度違うことと、購入価格も都度違うこと。今の管理は曖昧だと認識している。

### 3-2. 手入力と思われる単価がある【事実+推測】
- 一部の単価は「¥352」のように、ほかと違う書式になっている(例:ホワイトセージ、ベンゾイン、ブラックスプルース、ベチバー、ローレル、オスマンサスなど)。
- 【推測】価格表に載っていない精油を、手で入力している。その場合、価格が変わっても自動では更新されない。

### 3-3. テンプレートが少しずつずれている【事実】
- 「リベ_ゼラニウムピローミスト」だけ、列の並び順がほかと違う。
- 製造量の欄に「aw」という入力がある(2シート)。【推測】入力ミス。
- 一部のシートの下に、意味の分からない数字(1760、102)がある。【推測】販売価格などのメモ。要確認。

### 3-4. このシートに「ない」情報【事実】
- **在庫の残量**(今どの精油が何 ml 残っているか)
- **実際に買った記録**(いつ・どこで・いくらで・何本買ったか)。価格表は「カタログの定価」で、実際の購入価格ではない。
- **製造の記録**(いつ・どの処方を・何本作ったか)
- **IFRA に関する情報**(成分、上限、製品カテゴリ)
- 学名・産地・ロット・COA・SDS

## 4. ここから言えそうなこと【推測】

1. 「単価の管理が煩雑」の正体は、**価格の入力の手間** よりも、**どの単価を正とするか決まっていないこと** かもしれない。
2. 在庫の残量を出すには、「買った量 − 使った量」が必要になる。使った量は **製造の記録** と **処方** から計算できるが、今はどちらの記録も仕組みとしてない。
3. 処方・精油・購入・製造をつなげると、**原価・在庫・(将来的に)IFRA 確認** が同じデータから出せる。これは SQL でのデータ設計と相性がよい。
   - ただし 60時間で全部は作れない。どこから始めるかは要相談。
4. AI の出番の候補:原価や在庫の計算そのものは、決まった計算なので AI は不要。AI が活きるのは、**購入メール・納品書から購入記録を作る** といった「入力の手間」の部分かもしれない。

## 4.5 ひろみの補足(2026-11-05)

- 【事実】このシートは、**昔の滴数ベースのやり方** のときのもの。今は重さ(g)で配合している。
- 【推測】つまり、今の作り方に合った原価の記録は、現在ない。新しいツールは g ベースで設計し、ml で買った精油の単価を、比重で g あたりに換算する必要がある。
