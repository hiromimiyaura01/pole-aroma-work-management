## V1:手書きノートの読み取り精度(H1)

### やったこと【事実】
- 対象:以前にもらったノートの写真2枚に写っていた **3ページ**(Tea 004/012/013。試作版)。
- Claude(チャット)が写真を読み取って表にし、ひろみがノートと見比べた(2026-11-06)。
- 各グループの横に書かれた小計と、Claude が足し算した合計も比べた。

### 結果【事実】

| 項目 | 結果 |
|---|---|
| 読み取った配合行 | 34行 |
| Claude が自信を持って読んだ行 | 30行 → **すべて正解** |
| 「確認してください」の印をつけた行 | 4行 |
| 精油名・数字の誤り | **0行(0%)** |
| 判断の基準(数字の誤り 5%以下) | **満たした** |

印をつけた4行の内訳:

| 箇所 | Claude の扱い | 正解(ひろみ) | 評価 |
|---|---|---|---|
| 「Tea」がどのグループに入るか(かっこの外に見えた) | 小計が合うグループに入れ、印をつけた | Claude の判断どおり | 印は不要だったが、害はない |
| Hiba(かっこの外)×2ページ | 含めるか分からないとして、決めなかった | **含める** | 人に聞くのが正しかった |
| Amber の数字(書き直しで判読できない) | 判読不能とし、「小計に合わせるなら 5」と補足した | **10** | **小計に合わせた補足は誤りだった** |

### 分かったこと
- 【事実】このノートでは、ページの **小計が書き直しのあと更新されていない** ことがある(Tea 013 では、ミドル・ベースとも、配合の合計とノートの小計が合わない)。
- 【推測】ここから、設計上のルールを1つ決める必要がある。
  - **小計が合わないことは「警告」として出すが、AI が数字を小計に合わせて直してはいけない。** 今回、小計に合わせた推測(Amber=5)は誤りだった。
  - 読み取れない数字・かっこの外の記載は、AI が決めずに **必ず人に聞く**。今回の印の付け方は、この方針で正しく働いた。
- 【推測】汎用の OCR では読めなかった(`notes/2026-11-05_handwritten-notes-review.md`)のに対し、画像を理解できる AI では誤りがなかった。**写真からの読み取りを MVP の中心機能として採用してよい** と判断できる。

### この結果の限界
- 3ページだけで、ひろみの字はきれいな方。ページが増える・字が崩れると精度は下がるかもしれない。
- 今回はチャットの Claude で試した。MVP では Claude API を使うため、**同じ精度が出るかは MVP の中で Evals(正解データとの比較)で確かめる**。
- 見比べにかかった時間は未記録。

### 判断
- **H1 を支持する。** 写真からの読み取りを、MVP の中心機能として採用する。
- 正解データ(今回の3ページ+今後のページ)を、MVP の Evals に使う。

## V2:販売中のピローミストの手作業確認(H2・H3)

### やったこと【事実】(2026-11-06。3処方)
- ひろみが、販売中のピローミストから「INNOCENT」「GRACE」「HOPE」(いずれも精油7種)の配合をチャットで共有した。賦香率は **一律10%**。
- Claude が完成品中の濃度を計算し、IFRA 第51次改正のカテゴリ 11B と照らし合わせた。
  - 規制成分の含有率は、**IFRA の Annex(contributions from other sources)の典型値** を使った(`notes/2026-11-05_ifra-official-sources.md` 2.6)。
  - 同じ成分が複数の精油に含まれる場合は、**合計して** 上限と比べた。
- 配合・計算の途中経過はリポジトリに残さない。以下は件数と成分名だけ。

### 結果【事実】

「上限に近い」は、上限の **0.8倍以上** の成分(2026-11-06 にひろみが表示すると決定)。

| 処方 | 赤 | 黄(上限超え) | 上限に近い(0.8倍以上) | 未確認・近似など |
|---|---|---|---|---|
| INNOCENT | 0 | **1**(メチルオイゲノール:約7.3倍) | 1(ツヨン:約0.94倍) | 未確認の精油1(Annex に載っていない)、近似2 |
| GRACE | 0 | **1**(p-クレゾール:約1.03倍。ジャスミンは grandiflorum と確認) | 2(イソオイゲノール:約0.86倍、ツヨン:約0.94倍) | 近似2、基準本文の確認が必要1(ベンジルシアニド:「See Notebox」) |
| HOPE | 0 | **3**(ベルガモット油そのもの:約3.75倍 ※圧搾と確認/メチルオイゲノール:約3.6倍/ツヨン:約1.4倍) | 0 | 近似2、柑橘のフロクマリン(5-MOP)は未確認 |

- 同じ成分が複数の処方で繰り返し出た:**メチルオイゲノール(ティートリー由来)は2処方、ツヨン(フランキンセンス由来)は3処方すべて**。

- 【事実】黄の成分について、ひろみは「**成分名は知っていたが、注意は知らなかった**」。→ **H2 を支持**(知らなかった黄が1件以上)。
- 【事実】黄は1処方あたり 1〜3件で、基準の「5件」を下回った。→ **H3(アラート疲れしない)を支持**。
- 【推測】同じ精油が同じ黄を繰り返し出すので、「**この精油は、この製品カテゴリでは比率◯%までなら上限内**」を精油ごとに前もって計算して見せると、処方を作る段階で役に立つ可能性がある(決まった計算なので AI は不要)。MVP に入れるかは 07 で検討。

### 確認の途中で分かったこと
- 【事実】**Annex に、ひろみの精油とぴったり同じものがない場合がある**。
  - ホーウッド(木部、リナロールが多い):Annex には「Ho leaf oil」「Ho bark oil」しかない → 「Ho bark oil」で **近似**。
  - フランキンセンス(Boswellia serrata):Annex には「Olibanum oil(Boswellia spp.)」など → **近似**。
  - 【推測】精油と参考値の結びつきには、「一致」「近似」「なし(未確認)」の3段階が必要。近似のときは、どの参考値で代用したかを表示する。
- 【事実】**一覧表のデータに、そのままでは計算できない値がある**。
  - 例:上限が「0,10」(小数点がカンマ)、「See Notebox」(本文を読む必要がある)、「No Restriction」。
  - 【推測】IFRA の表をデータベースに取り込むとき、**値の整形(データクレンジング)と、「本文の確認が必要」というフラグ** が要る。SQL の設計で扱う論点。
- 【事実】**名前の表記揺れ**:ひろみは「マジョラム」と書くが、スイートマジョラムとスパニッシュマジョラムの両方を使っている。両者は別の植物(Origanum majorana/Thymus mastichina)で、Annex 上の規制成分も違う。
  - 【事実】ひろみの要望:「自分の中でだいたいこう書く、というのがあるから、**表記揺れを登録できると作業が早い**」。

## V3:成分・比重の参考値(H5)

### 結果【事実】
- IFRA の規制成分については、生活の木・THREE より **IFRA の Annex が直接使えた**(公式資料で、精油ごとの規制成分の典型値が載っている)。
- 3処方で使った精油(延べ21、種類では15前後)のうち:
  - Annex で **一致**:大部分
  - **近似**(ぴったり同じものがなく、近いもので代用):ホーウッド(Ho bark oil で代用)、フランキンセンス serrata(Boswellia spp. で代用)
  - **未確認**(Annex に載っていない):カモミールローマン(1種類)
- 「未確認の精油あり」のフラグが立った処方:**3処方中1処方**(INNOCENT)
- Annex では確かめられないもの:柑橘の **フロクマリン(5-MOP)** の含有率。柑橘を使う処方すべてに関わる。

### 判断
- 基準「フラグが立つのが 0〜1処方 → 今の出典で進める」を満たした。→ **H5 を支持**。成分の参考値は **IFRA の Annex を第一の出典** にし、生活の木・THREE は補足(と比重)に使う。
- ただし、**柑橘のフロクマリンの参考値は別途探す必要がある**(ピローミストは 11B=光毒性を考える区分なので、重要)。

## ひろみの判断【事実】(2026-11-06)

- 3処方の黄は、現状は「**意図して超えるもの**」とする。「後々処方を変更するかも」。
- これは、ひろみが判断材料(上限との比)を見たうえで決めたもの。Claude は法的な判断をしていない。
- 【推測】MVP では、この判断を処方ごとに記録できるようにする(「意図して超えた」の記録)。今回の3処方が、その最初の実例になる。
