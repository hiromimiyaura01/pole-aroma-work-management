## 0. 結論(先に)

- 【推測】日本で「自分で処方を作り、アロマスプレー類を販売し、安全性を重視する」作り手は、**数人〜数十人規模** と見積もった(ひろみの体感で下方修正。2.を参照)。
- 【推測】このプロダクトを **単体の有料サービスとして事業にするには、日本だけでは小さすぎる**。
- それでもこの市場を選ぶ理由は、事業の大きさではなく次の4つ(4. を参照)。
  1. ひろみ自身の **実在する課題** で、検証と効果測定ができる
  2. ポートフォリオ・AX の学びとして、**課題設定 → 検証 → MVP → 計測** を一通り示せる
  3. 英語圏には、隣の市場(キャンドル・石鹸作家向け)で **お金を払うツールが成り立っている** 例がある
  4. ここで作るデータ(処方・精油・成分・IFRA の基準)が、**次のプロダクト**(香りの提案)の土台になる

### フェルミ推定【推測】

| ステップ | 仮定 | 値 |
|---|---|---|
| ① Creema でアロマスプレー類を出品している作り手 | 1,354件 ÷ 1人あたり3〜5作品 | 約270〜450人 |
| ② minne・BASE・自社サイト・イベントを含めた全体 | ①の2〜3倍(マーケットの重なりは考えない) | 約550〜1,350人 |
| ③ そのうち「自分で処方を作り、製造している」人 | 7〜9割(ハンドメイドなので多くは自作と仮定) | 約400〜1,200人 |
| ④ そのうち「安全性や根拠を重視している」人 | **0.5〜5%**(下記) | **約2〜60人** |

- 【事実】④の割合について、ひろみの体感は「**全然わからないけど、1人も会ったことないレベル**」(2026-11-06)。最初は1〜3割と仮置きしていたが、0.5〜5%に下げた。
- 【推測】ただし、安全性を重視する作り手は表に出にくい(発信しない)可能性もあるので、「会ったことがない=いない」とは限らない。
- ピローミストだけに絞ると、①は約20〜35人で、④は数人〜数十人になる。

### お金の大きさ(参考)【推測】
- 仮に月額 500〜1,500円で使ってもらえるとすると、④の全員で **年間 約1万〜100万円**。
- → 事業としての SaaS には小さい。**「事業として成り立つか」はこのプロジェクトの判断基準にしない**(ポートフォリオ・自分用・学びが目的のため)。

## 4. なぜこの市場を選ぶのか

- **選ぶ理由**:0. の4つ。とくに「ひろみ自身の課題で、事前検証で価値を確かめられた」(05:3処方すべてで知らなかった注意が見つかった)ことが大きい。
- **選ばない理由になりうること(正直に)**:
  - 市場が小さいので、「多くの人に使ってもらって改善する」流れはポートフォリオで示しにくい。
  - → 代わりに、**1人の業務を深く変えて、その効果を数字で示す**(AX の「小さく始めて、効果を測ってから広げる」)ことを見せる。
