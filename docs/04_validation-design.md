# 04 検証の設計

前提:`01` v1.0、`02` v1.0、`03` v1.0。検証の対象はひろみ自身(**n=1**)。仲間へのヒアリングは行わない。

---

## 1. この文書の目的

- MVP を作る **前に**、コードを書かずに確かめられることを確かめる。作ってから「要らなかった」と分かるのを避ける。
- MVP を使う **前の数字(ベースライン)** を記録し、MVP の効果を比べられるようにする。
- それぞれの検証に、**「こうなったら方針を変える」という判断の基準** を先に決めておく。

## 3. MVP の前にやる検証(コードを書かない)

### V1:手書きノートの読み取り精度(H1)
- **やり方**
  1. ひろみが、完成版の処方ノートを **5〜10ページ** 撮影する(JPEG か PNG)。
  2. Claude(チャット)に「香りの処方ノートである」という前提を伝えて、表の形に読み取らせる。
  3. ひろみが正解と見比べて、**配合行ごとに** 正しく読めたかを数える。
- **数えるもの**
  - 精油名の誤り(略称の名寄せを含む)
  - 数字の誤り
  - グループ・小計の誤り
  - 「確認してください」と印をつけるべきだったのに、つけなかった箇所
- **判断の基準(案)**
  - 数字の誤りが **配合行の5%以下**、かつ曖昧な箇所に印がつく → MVP の中心機能として採用する。
  - 数字の誤りが **5%を超える** → 写真は「下書きの補助」にとどめ、手入力の画面を中心にする。
  - ※ 5% という値は仮置き。ひろみと相談して決める。
- **注意**:処方は企業秘密にあたる。読み取りの結果はリポジトリに残さず、**誤りの数だけを記録する**。

### V2:販売中のピローミストを手作業で確認する(H2・H3)
- **やり方**(コンシェルジュ型:ツールの代わりに、人が手で同じことをやってみる)
  1. 販売中のピローミストの処方を **3つ** 選ぶ。
  2. 処方ごとに、精油の比率と賦香率から、完成品中の濃度を計算する。
     - 完成品中の濃度 = (その精油の比率 ÷ 比率の合計) × 賦香率
  3. IFRA の一覧表(第51次改正)の **カテゴリ 11B** と照らし合わせる。
     - 精油そのものの基準(例:圧搾ベルガモット、オークモス)
     - 精油に含まれる成分の基準(生活の木・THREE 研究サイトの成分参考値を使う)
  4. 「赤」「黄」「なし」に分けて数える。
- **役割分担**:計算と照らし合わせは Claude が手伝う。**どの精油を使ったか、どう判断するかはひろみが決める**。
- **数えるもの**
  - 赤・黄の件数(処方ごと)
  - そのうち、**ひろみが知らなかったもの** の件数
  - 1処方の確認にかかった時間
  - 成分の参考値が見つからなかった精油の数
- **判断の基準(案)**
  - 知らなかった赤・黄が **1件以上** 見つかる → ①の価値がある(H2 を支持)。
  - 1件も見つからない → ①の優先度を下げ、②(在庫・原価)を先にするか検討する。
  - 黄が **1処方で5件を超える** → 表示の工夫(まとめ表示、「意図して超えた」の記録)を MVP の必須にする。
    - 2026-11-06 に 10件 → 5件 に変更。理由:1処方の精油は6〜20種類程度なので、10件では多すぎる(ひろみの判断)。

### V3:成分・比重の参考値が集まるか(H5)
- **やり方**:V2 で使った精油について、生活の木・THREE 研究サイトで成分と比重を調べる。
- **なぜ確かめるのか**:成分の参考値がない精油は、含まれる規制成分を確かめられない。それなのに「赤・黄なし」と表示されると、**本当は確かめていないのに「問題なし」に見えてしまう**(安心しすぎてしまう)。
  - 「この精油は成分が分からないので確認できていない」という表示は、**どの場合でも最低限は必要**。
  - この検証で決めるのは、その表示を **どこまで作り込むか**、参考値の出典を **増やす必要があるか**。
- **表示の方針**(2026-11-06 決定。ひろみの提案)
  - 「赤・黄」とは **別のフラグ** として、**「未確認の精油あり」** を持つ。あわせて、どの精油が未確認かを一覧で出す(比率も並べて表示する)。
  - これで「確かめていないのに問題なしに見える」状態は防げる。比率が大きい未確認精油か、小さいものかは、一覧を見てひろみが判断する。
  - カバー率(%)の計算は持たない。フラグと一覧で判断できるため。
- **数えるもの**
  - 3処方のうち、「未確認の精油あり」のフラグが立つ処方の数
  - 未確認になった精油の名前の一覧(処方の中の比率の大きさも、メモとして見る)
  - 1精油あたりの調べる時間
- **判断の基準(案)**
  - フラグが立つのが **0〜1処方** → 今の参考値の出典(生活の木・THREE 研究サイト)で進める。
  - **3処方すべて** にフラグが立ち、しかも比率の大きい精油が未確認 → 確認の意味が薄くなるので、参考値の出典を増やすか検討する。
  - その中間(2処方)→ 未確認になった精油を見て、ひろみと判断する。
  - 経緯:「精油の種類の 7割」→「配合比率で重みをつけたカバー率 90%」→「未確認フラグ+一覧」と見直した(2026-11-06)。

## 3.5 実施計画(2026-11-06 決定)

- 【事実】ひろみの決定:事前検証は **2時間だけ** 行う。販売中のピローミストは **12処方**。そのうち3つを選べる。
- 2時間に収めるため、**V1・V2・V3 を同じ3処方で、1つの流れとして行う**。

| 手順 | 担当 | 目安 | 対応する検証 |
|---|---|---|---|
| 1. 12処方から3つ選ぶ(柑橘が多いもの/気になる原料を含むもの/シンプルなもの、のように性格の違うもの) | ひろみ | 10分 | — |
| 2. 3処方の完成版ノートを撮影して共有フォルダに置き、それぞれの賦香率を伝える | ひろみ | 10分 | — |
| 3. Claude が写真を読み取って表にする。ひろみが正解と見比べ、誤りを数える | Claude → ひろみ | 20分 | V1 |
| 4. Claude が完成品中の濃度を計算し、IFRA 第51次改正のカテゴリ 11B と照らし合わせて、赤・黄の候補を出す | Claude | (ひろみの時間は使わない) | V2・V3 |
| 5. ひろみが赤・黄の候補を見て、「知らなかったか」「どう判断するか」を決める | ひろみ | 40分 | V2 |
| 6. 結果を数字だけ記録し、判断の基準と照らし合わせる | Claude → ひろみ | 20分 | 全体 |

- **照らし合わせの範囲**(2時間に収めるための絞り込み)
  - 精油そのものにかかる基準(例:圧搾ベルガモット、オークモス、柑橘油のフロクマリン、Tea leaf absolute)
  - 精油に含まれる主な成分のうち、基準がある成分(生活の木・THREE 研究サイトの参考値を使う)
  - Annex(contributions from other sources)を使った網羅的な確認は、今回は行わない。
- **処方の扱い**:写真・配合・計算の途中経過はリポジトリに残さない。記録するのは件数・割合・時間だけ。
- **判断の基準**:3. の値(5%、1件、5件、未確認フラグの処方数)は仮置きのまま進め、結果を見てひろみと見直す。

## 4. ベースライン(MVP を使う前の数字)

| # | 指標 | 今の値 | 取り方 |
|---|---|---|---|
| B1 | 1処方をノートからシートに書き起こす時間 | 未計測 | 次に処方を書き起こすとき、ひろみがかかった時間をメモする(2〜3回) |
| B2 | 棚卸しの時間と頻度 | 【事実】約2か月に1回、1回約2時間(ひろみの申告) | 申告値を使う。次回の棚卸しで実測できればなおよい |

| B4 | 原価の根拠が分かる処方の割合 | 【推測】ほぼ0%(「赤字にはならんっしょ」) | ②の前に確認する |

## 5. MVP の後の検証(09 で詳しく設計する)

- B1・B3 を、MVP を使ったあとで測り直す。
- 手書き読み取りの、**ひろみが直した箇所の数** を記録する(AI の精度を継続的に測る)。
- 「赤・黄」のうち、ひろみが **処方を変えた件数** と **意図して超えたと記録した件数** を数える。

## 6. n=1 の検証の限界

- 結果は「ひろみの事業では効果があった」という事実にとどまる。ほかの事業者に当てはまるかは、06(公開情報)と MVP 後の知り合い1名で補う。
- ひろみ自身が検証者でもあるので、結果を良く見たくなる偏りがありうる。**判断の基準を先に決めておく** のは、そのため。
